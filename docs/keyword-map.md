# JichangPlus 机场加 关键词聚类与页面规划映射表

## 1. 核心商业与管理关键词聚类
- **集群 A：订阅日常管理与维护** (`/subscription-management/`)
  - 核心词：机场订阅管理、机场订阅更新、机场节点管理、订阅整理、订阅链接安全。
  - 承载意图：解决用户拥有订阅后的日常刷新、去重、备份与容灾问题。
- **集群 B：多设备与家庭网络协同** (`/multi-device/`)
  - 核心词：机场多设备使用、设备协同、家庭共享、Windows/Mac/iOS/Android 设置、局域网共享代理。
  - 承载意图：解决多端配置不一致、多设备同时在线并发限制与智能家居分流。
- **集群 C：流量规划与节点智能选择** (`/traffic-nodes/`)
  - 核心词：机场流量管理、机场流量怎么算、流量不够用、节点选择、倍率计算、测速技巧。
  - 承载意图：消除流量焦虑，帮助用户理解不同线路成本与日常选择习惯。
- **集群 D：主流客户端调优技巧** (`/client-tips/`)
  - 核心词：Clash 使用技巧、Shadowrocket 技巧、sing-box 进阶、Stash 规则、TUN 虚拟网卡模式。
  - 承载意图：深化客户端进阶功能认知，解决规则覆写与 DNS 防污染。
- **集群 E：安全常识与合规使用习惯** (`/safe-use/`)
  - 核心词：机场安全使用、账号安全、2FA、密码管理器、公共网络防泄露。
  - 承载意图：强化网络工具使用的安全边界，保护敏感资产。
- **集群 F：自营/精选服务说明与适配** (`/service/` 与 `/providers/`)
  - 核心词：机场订阅服务、全球云、飞猫云、暮光加速、微风网络、设备适配。
  - 承载意图：承接已建立信任读者的商业转化需求，提供客观透明的套餐核验与邀请入口。
- **集群 G：高频问题中心** (`/faq/`)
  - 核心词：机场使用 FAQ、100 个精准长尾问题（涵盖 9 大主题配额）。
  - 承载意图：长尾搜索意图捕获，以 130~240 字精准回答结合系列文章内链。

## 2. 合规与负面拦截说明
- 带有“翻墙、突破封锁、保证解锁、永久稳定”等违反平台与合规政策的词汇，以及“三毛机场、猫梦博客”等第三方参考发布者品牌，已全部标记为 `不用于公开页面` 并纳入自动化拦截，禁止进入公开构建产物。
